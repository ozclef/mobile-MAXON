## 2. OXXO CEL: todavía no está activado

Aquí hay una distinción importante: que el chip sea reconocido por Android no significa que la línea ya esté activada.

Según el procedimiento oficial de OXXO CEL:

1. Necesitas una recarga inicial de $50 o más.
2. Insertas el chip.
3. Recibes un SMS para vincular tu línea.
4. Completas el procedimiento y recibes confirmación de activación.

Página oficial: Activar chip OXXO CEL.

**registro de líneas en México, 2026**

También existe el procedimiento de vinculación de la línea con tu identidad, mediante el portal oficial de OXXO CEL.

Vincular línea OXXO CEL.

No confundas la activación comercial con el registro de identidad: son pasos relacionados, pero distintos.

## 4. Lo de Google y Chrome

Aquí sí quiero investigar contigo porque dices que Chrome tiene configuraciones que limitan la carga de páginas.

Puede deberse a:

- Restricciones de datos o ahorro de datos.
- DNS privado.
- Fecha y hora incorrectas.
- Servicios de Google desactualizados.
- Certificados o configuración de seguridad.

Prueba esto:

**Ajustes → Red e Internet → DNS privado**

Comprueba que esté en Automático o Desactivado temporalmente.

Después revisa:

**Ajustes → Aplicaciones → Chrome → Almacenamiento y caché**


## 5. El cargador V8 y la batería

El conector V8 es el antiguo micro-USB.

Con una batería de 1,800 mAh:

- Utiliza un cargador de buena calidad.
- Comprueba que no se caliente demasiado.
- Evita dejarlo conectado si notas calentamiento anormal.
- Revisa que el puerto no tenga holgura.

Y conserva el cargador original si funciona correctamente.
